# Calculator

A simple and responsive calculator web application built as part of the **Oasis Infobyte Web Development Internship – Level 2**.

## Overview

This project is a functional calculator that allows users to perform basic arithmetic operations through a clean and responsive interface.

The calculator displays the numbers and selected operator as the user builds an expression, then calculates the result when the equals button is pressed.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Decimal number calculations
* Clear button
* Division-by-zero error handling
* Displays both numbers and the selected operator
* Responsive design for different screen sizes
* Interactive button effects

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Run

1. Clone or download the project.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Use the calculator buttons to perform calculations.

## Calculator Operations

The calculator supports:

```text
Addition       7 + 3  = 10
Subtraction    10 - 4 = 6
Multiplication 6 × 5  = 30
Division       20 ÷ 4 = 5
Decimals       3.5 + 2.5 = 6
```

The calculator also prevents division by zero and displays an error message when an invalid division is attempted.
