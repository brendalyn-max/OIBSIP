# Brendalyn Musoki — Personal Portfolio

A responsive personal portfolio website showcasing my skills, projects, and professional journey as a Software & AI Engineer.

##  About the Project

This portfolio was built as part of my **Oasis Infobyte Web Development Internship**.

The goal was to create a clean, responsive, and professional personal website that introduces me, highlights my technical skills, showcases selected projects, and provides a way for people to connect with me.

##  Features

* Responsive design for desktop, tablet, and mobile screens
* Personal hero section with profile photo and introduction
* About Me section
* Technical skills section with technology icons
* Featured projects section
* Links to project repositories
* Contact section with email and social links
* Light and dark mode
* Smooth navigation between sections
* Hover effects and interactive elements
* Accessible navigation and image alternative text
