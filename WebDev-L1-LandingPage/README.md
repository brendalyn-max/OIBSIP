SwiftLink — Logistics Landing Page
Overview

SwiftLink is a fictional African logistics technology startup created as part of the Oasis Infobyte Web Development Internship.

The landing page presents SwiftLink as a modern logistics platform designed to help businesses manage deliveries and connect with customers more efficiently.

Project Objective

The goal of this project was to build a visually polished and responsive static landing page using foundational HTML5 and CSS3 skills.

Features
Sticky navigation bar
Hero section with headline, supporting text, and call-to-action
Logistics delivery tracking visual
Business delivery solutions section
About section focused on African businesses
Three-step "How It Works" section
Call-to-action section
Footer with placeholder contact and social links
Responsive layout for desktop, tablet, and mobile screens
Consistent colour palette and typography
CSS Flexbox and Grid layouts
No JavaScript
Tech Stack
HTML5
CSS3
Design

SwiftLink uses a modern technology-focused visual style combining:

Deep violet for trust and professionalism
Lilac as the primary accent colour
Soft lilac-white backgrounds
Large typography
Rounded cards
Responsive layouts
Generous spacing
Minimal, modern visual elements
Responsive Design

The landing page uses CSS Grid, Flexbox, relative sizing, and media queries to adapt the layout across different screen sizes.

The navigation also includes a CSS-only mobile menu, allowing users to access the navigation links on smaller screens without JavaScript.
