# King Oyo Rukidi IV — Tribute Page

## Overview

This project is a tribute page dedicated to **King Oyo Nyimba Kabamba Iguru Rukidi IV**, the Omukama of Tooro Kingdom.

The page presents a brief biography, important moments from his life and leadership, and a reflection on his cultural and social legacy.

## Project Objective

The objective of this project was to build a responsive and visually appealing tribute page using HTML and CSS.

The project focuses on:

* Semantic HTML structure
* Responsive web design
* Modern and elegant UI design
* Image presentation
* Timeline-based content
* Typography and spacing
* Accessible image descriptions

## Technologies Used

* HTML5
* CSS3

## Features

* Modern royal-inspired design
* Responsive layout for desktop and mobile devices
* Black-and-white portrait image
* Biography section
* Timeline of key moments
* Tribute quote section
* Responsive navigation through page structure
* Semantic HTML elements
